## 设计思路

### 核心数据结构

```cpp
class Rational {
private:
    std::int64_t num_;   // 分子
    std::int64_t den_;   // 分母 (恒为正)
};
```

**设计决策：**

| 决策 | 理由 |
|------|------|
| `int64_t` 而非 `int` | 防止大数乘法溢出，64 位范围 ±9.22×10¹⁸ |
| 分母恒为正 | 规范化：`6/(-9)` → `-2/3`，符号统一在分子 |
| 构造时自动约分 | 外部无需手动调 `simplify()`，封装性更好 |
| 分子为 0 时分母归一化为 1 | `0/5` → `0`，避免输出歧义 |

### 封装性体现

1. **数据成员 `private`**：外部只能通过 `numerator()` / `denominator()` 只读访问，杜绝外部篡改
2. **构造时校验**：分母为零直接抛 `std::invalid_argument`
3. **自动规范化**：所有运算后的对象必定处于最简状态（约分 + 分母为正）

### 构造函数重载

```cpp
Rational();                              // 默认: 0/1
explicit Rational(std::int64_t n);       // 整数: n/1
Rational(std::int64_t num, std::int64_t den);  // 分数: 自动约分
```

`explicit` 禁止隐式类型转换，防止 `Rational r = 5` 这种容易误解的写法。

### 四则运算与防溢出

```
a/b + c/d = (a*d + b*c) / (b*d)
a/b - c/d = (a*d - b*c) / (b*d)
a/b * c/d = (a*c) / (b*d)
a/b ÷ c/d = (a*d) / (b*c)    // c ≠ 0
```

- 构造时自动调用 `simplify()` 约分，控制中间结果膨胀
- 理论上可用 `__int128` 做中间乘法（GCC 支持），MSVC 下 `int64_t` 直接乘在大多数分数运算中足够

### C++20 三路比较 `<=>`

```cpp
std::strong_ordering operator<=>(const Rational& rhs) const;
```

实现为 `num_ * rhs.den_ <=> rhs.num_ * den_`（交叉乘法），编译器自动生成 `<`, `<=`, `>`, `>=` 四种运算符。`operator==` 同时 `= default`。

## 使用方法

### 编译

```powershell
# VS 2022 MSVC (需要先设置 INCLUDE/LIB 环境变量)
cl /EHsc /std:c++20 /utf-8 /Fe:rational_demo.exe rational.cpp main.cpp
```

> **注意**：`/utf-8` 标志必须加，否则中文注释在 MSVC 默认 GBK 代码页下报 C4819 警告导致编译失败。

### 运行

```
.\rational_demo.exe
```

## 技术要点总结

| 特性 | 实现方式 |
|------|----------|
| 封装 | private 成员 + public 只读访问器 |
| 构造重载 | 默认 / 单参 (explicit) / 双参 |
| 约分化简 | 辗转相除法 GCD |
| 四则运算 | `+` `-` `*` `/` 运算符重载 |
| 复合赋值 | `+=` `-=` `*=` `/=` |
| 比较 | C++20 `<=>` 三路比较 |
| 流输出 | `operator<<` 友元函数 |
| 异常安全 | 分母为零 / 除数为零 → `std::invalid_argument` |
| 数据安全 | `int64_t` 防止溢出，分母恒为正 |
