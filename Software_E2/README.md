# Software_E2 — 手写数字识别：MLP vs CNN

## 自我介绍

我是张杨亦航（学号 2524030231）。这道题是机器学习方向的第二个题目，系统对比了全连接网络（MLP）和卷积神经网络（CNN）在 MNIST 手写数字识别上的表现。之前写 E1 时手动实现了反向传播，这次用 PyTorch 框架来完成更接近工业实践的模型对比。

本地是 RTX 5070 但当前 PyTorch 是 CPU 版本（Python 3.14 的 CUDA wheel 需要 nightly build），所有结果均在 CPU 上完成。MNIST 数据量小（60k 训练 + 10k 测试），CPU 完全够用。

## 实验结果

### 超参数调优

| 配置 | Batch | LR | Acc |
|------|:-----:|:--:|:---:|
| 基线: 单隐层 128 | 64 | 0.001 | 97.98% |
| 加深: (256,128)+Drop0.2 | 64 | 0.001 | 98.48% |
| 调参: batch_size=128 | 128 | 0.001 | 98.48% |
| 调参: lr=0.003 | 64 | 0.003 | 98.48% |
| **最优**: (512,256,128)+Drop0.3 | 64 | 0.001 | **98.64%** |

**分析**：
- 加深网络 (+256→128) 带来最大提升 (+0.5%)
- batch_size 从 64 到 128 影响不大
- lr=0.003 比 0.001 收敛快但最终精度略低

### MLP vs CNN 对比

| 指标 | MLP | CNN |
|------|:---:|:---:|
| 网络结构 | (512,256,128) 全连接 | Conv(32→64) + FC(128) |
| 参数量 | ~670K | 225K |
| Top-1 Acc | **98.64%** | **99.48%** |
| Top-5 Acc | 99.96% | 100.00% |
| 单 epoch 耗时 (CPU) | ~1s | ~12.6s |

**CNN 胜出**：参数少 3 倍，准确率更高。原因：
1. **参数共享**：卷积核在整张图上滑动，同一模式（边缘/纹理）只学一次
2. **局部感受野**：每个神经元只看局部区域，更符合图像的空间结构
3. **平移不变性**：MaxPooling 让特征对位置微小偏移不敏感

### Top-k 准确率

| k | MLP | CNN |
|:--:|:---:|:---:|
| Top-1 | 98.64% | 99.48% |
| Top-2 | 99.58% | 99.93% |
| Top-3 | 99.82% | 99.98% |
| Top-4 | 99.91% | 99.99% |
| Top-5 | 99.96% | 100.00% |

**Top-k 含义**：真实标签出现在模型预测的前 k 个类别中的概率。在 MNIST (10 类) 中 Top-5 几乎总是 100%；在 ImageNet (1000 类) 中 Top-5 是衡量模型"语义理解"的重要指标——即使第一名预测错了，模型可能已经把正确类别排在了前几名。
