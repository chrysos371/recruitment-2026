## 算法设计

### 整体流程

```
输入图像
  ↓ BGR → HSV 颜色空间转换
  ↓
为 红/黄/绿 各创建颜色掩码
  ├─ 红色: 两段 HSV 范围 (跨越 0° 分界线)
  ├─ 黄色: 一段 HSV 范围
  └─ 绿色: 一段 HSV 范围
  ↓
暗光场景: 降低 V 阈值重新检测
  ↓
形态学处理
  ├─ 开运算 (Open): 去除小噪点
  └─ 闭运算 (Close): 填充孔洞, 连接断裂
  ↓
轮廓检测 + 几何过滤
  ├─ 面积: 20-5000 px² (滤噪点+广告牌)
  ├─ 圆形度: > 0.3 (滤不规则形状)
  ├─ 长宽比: < 3.0 (滤长条形)
  └─ 位置: 底部 30% 降权 (滤尾灯)
  ↓
输出: 信号灯状态 + 绘制检测框
```

### 鲁棒性设计

| 干扰场景 | 应对方案 |
|----------|----------|
| **阳光反光** | HSV 饱和度下限 150（白色反光饱和度低，被滤除）|
| **夜晚灯光** | 暗通道检测：图像平均灰度 < 80 时降低 V 阈值 |
| **红色尾灯** | 位置过滤：图像底部 30% 区域置信度 ×0.3 |
| **绿色广告牌** | 面积上限 5000 + 圆形度下限 0.3（广告牌大且不规则）|
| **摄像头抖动** | 闭运算连接因抖动导致的断裂区域 |

### HSV 颜色范围

```
红色: H∈[0,10]∪[160,180], S∈[150,255], V∈[80,255]
黄色: H∈[18,33],  S∈[120,255], V∈[120,255]
绿色: H∈[60,85],  S∈[120,255], V∈[120,255]
```

> 绿色 H 下限从 45 提到 60：交通绿灯是较纯的正绿（H≈60-85），
> 黄绿/青绿（H<60）常见于树叶、草地、反光，是绿色过检的主要来源。

## 技术要点

| 技术 | 函数/方法 | 作用 |
|------|-----------|------|
| 颜色空间 | `cv2.cvtColor(BGR2HSV)` | HSV 分离色调/饱和度/明度 |
| 阈值分割 | `cv2.inRange()` | 创建二值颜色掩码 |
| 形态学 | `cv2.morphologyEx(OPEN/CLOSE)` | 去噪+连接 |
| 轮廓分析 | `cv2.findContours()` | 提取连通区域 |
| 圆形度 | `4πA/P²` | 红绿灯是圆形 |
| 颜色强度 | `mean(S×V)/255²` | 区分点亮灯与暗淡灯罩/背景 |

## 干扰数据集与鲁棒性验证

`augment_and_test.py` 对全部 40 张原始图各生成 6 类增强（5 干扰 + 1 熄灭），共 240 张干扰图，再对增强图跑检测，统计状态在干扰前后是否一致（鲁棒率）。

| 干扰类型 | 鲁棒率 | 状态分布 | 说明 |
|----------|:-----:|----------|------|
| 阳光反光 | **87.5%** | 基本保持原状 | S 阈值有效滤除白色反光 |
| 夜晚灯光 | 40.0% | 偏向 yellow | 暗光下 V 自适应阈值偏向黄 |
| 红色车尾灯 | 57.5% | 偏向 red | 位置降权减轻但未根除 |
| 绿色广告牌 | 55.0% | red/green/off 混合 | 面积+圆形度过滤部分生效 |
| 摄像头抖动 | 47.5% | 红黄混合 | 闭运算部分连接断裂 |
| **熄灭** | —（应判为 off） | **off: 40/40 (100%)** | 灯灭后正确返回 off |

> 熄灭状态的"鲁棒率"无意义（它的目的就是让状态改变），故单独看：40/40 全部正确判为 `off`。

## 局限性（诚实交代）

- 传统 CV 方法无法完美区分红色尾灯和红色信号灯（仅靠位置启发式）
- 极端光照（强逆光）下 HSV 饱和度可能不足以区分
- 复杂城市场景中绿色植被可能被误检
- 对于题目要求的鲁棒性场景（反光/夜灯/尾灯/广告牌），算法做了针对性设计但无法保证 100% 准确
